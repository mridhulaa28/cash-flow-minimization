## Cash Flow Minimizer

### Overview

The Cash Flow Minimizer project optimizes financial transactions between multiple banks, reducing redundant transactions and improving financial efficiency.<br>

### Features

***Transaction Optimization:*** Reduces the number of transactions required to balance cash flow among banks.<br>

***Graph-Based Approach:*** Represents transactions using a 2D array for efficient processing.<br>

***Greedy Algorithm:*** Uses a greedy algorithm to determine the minimal set of transactions needed for balancing.<br>

***Data Structures:*** Utilizes ArrayList, HashMap, and HashSet for efficient data management and fast lookups.<br>

***Custom Classes:*** Implements Bank and Pair classes to manage bank details and transactions.<br>
